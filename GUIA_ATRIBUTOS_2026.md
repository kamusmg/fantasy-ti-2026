# Guia Fantasy – Função + Ranking de Atributos (Atualizado TI 2026)

Este guia define a meta absoluta e o ranking de atributos (emblemas) para o Fantasy do The International 2026. Use essas prioridades para tomar decisões sobre quais atributos escolher na hora de preencher os palpites das posições (Core, Mid, Support).

**IMPORTANTE:** O padrão de encaixe perfeito neste ano é:
- **CORE:** Vermelho / Verde / Vermelho
- **MID:** Vermelho / Azul / Verde
- **SUPPORT:** Azul / Verde / Azul

---

### CORE
- **Vermelhos (principais):** 
  - **Top:** Criaturas (Creep Score), GPM
  - **Médio:** Torres (Tower Kills), Abates (Kills)
  - **Ruim:** Pedras Loucas (Madstones Collected)
- **Azuis (secundários):** *Quase irrelevante pro core (Prioridade R/G/R)*
- **Verdes (principais):** 
  - **Top:** Lutas em Equipe (Teamfight Participation), Tormentas (Tormentor Kills)
  - **Médio:** Roshan
  - **Ruim:** -
- **Ranking Geral (CORE):**
  - **Top:** Criaturas / GPM / Lutas em Equipe
  - **Médio:** Tormentas / Torres / Roshan
  - **Ruim:** Pedras Loucas

---

### MID

  - **Ruim:** -
- **Verdes (principais):**

### SUPPORT
- **Vermelhos (secundários):** *Vermelho geralmente ruim pro sup (Prioridade B/G/B)*
- **Azuis (principais):** 
  - **Top:** Sentinelas (Wards Placed)
  - **Médio:** Acampamentos (Camps Stacked), Fumaças (Smoke of Deceit)
  - **Ruim:** Lótus (Lotuses Gained)
- **Verdes (principais):** 
  - **Top:** Lutas em Equipe (Teamfight Participation)
  - **Médio:** Atordoamentos (Stuns)
  - **Ruim:** Primeira Vítima (First Blood), Entregadores (Courier Kills)
- **Ranking Geral (SUPPORT):**
  - **Top:** Sentinelas / Lutas em Equipe
  - **Médio:** Stacks / Stuns / Fumaças
  - **Ruim:** Primeira Vítima / Lótus / Entregadores

---

### Notas de Estratégia para a IA:
1. **Atributo > Tier:** Não importa se o emblema é Dourado ou Divino se o atributo for ruim (ex: "Lótus" num Suporte). O foco primário é acertar os atributos "Top".
2. **Sentinelas é a Chave:** O atributo azul de Sentinelas (Wards) para Suportes é o maior divisor de águas estatístico do torneio.
3. **Evitar RNG:** Atributos como "Primeira Vítima" e "Lótus" têm alta variância e devem ser preteridos em favor de atributos consistentes (GPM, Lutas em Equipe, Criaturas).
